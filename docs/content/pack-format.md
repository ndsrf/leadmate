# Content Pack Format

The complete specification and authoring guide for LeadMate Content Packs is located at:

👉 [**`content/FORMAT.md`**](../../content/FORMAT.md)

See `content/FORMAT.md` for:
- Full directory layout and file formats (`pack.yaml`, `worlds/*.yaml`, `lessons/`, `nodes/`, `missions/`)
- Field definition tables generated directly from the schema
- Markdown rules and section mapping (Spanish required, language fallback)
- Image, animation, and video reference rules
- Authoring commands (`content:validate`, `content:promote`, `content:publish`, `content:watch`)
- Complete worked examples of Lessons and Missions
- Author and AI agent checklist
