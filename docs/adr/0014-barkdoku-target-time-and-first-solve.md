# Barkdoku Stars Use the Target Time, and Only the First Daily Solve Counts

Stars were meant to reflect handling quality only, never time. Barkdoku is the exception: a non-tutorial board needs a clean solve within its Target Time for 3 Stars, because in a deduction puzzle speed is part of the skill being practised, and a mistake-only rating gives most players 3 Stars by trial and error. Tutorial boards have no Target Time, so reading the rules the first time is never penalised. The Daily Barkdoku is a fixed board with one solution, so a replay is memory, not deduction: only the first solve of a date sets its Daily Solve Time and Stars, is logged and credits the Streak, and later solves that day are practice that changes nothing. On sync, the earlier first solve wins.

## Considered Options

- **Stars from mistakes only, time shown beside them**: keeps the old rule intact, but gives the clock no weight and leaves 3 Stars nearly automatic. Rejected.
- **Every Daily solve counts, fastest wins** (as the Daily Stage keeps its best score): a Daily Stage run varies and rewards replaying; a fixed puzzle replayed from memory gives a meaningless time. Rejected.
- **Lock the board after the first solve**: honest, but removes harmless practice. Rejected.
